# 0009. Nonce-based CSP

Status: accepted 2026-11-10
Context: PayRun is an authenticated admin app. Every page is dynamic (session-dependent), so per-request nonces cost nothing extra in rendering.
Options:
1. **Nonce-based `script-src 'nonce-…' 'strict-dynamic'`**, set in the request interceptor, which Next.js applies to its own scripts. `style-src 'self' 'unsafe-inline'` (Tailwind/shadcn inject inline styles; low risk).
2. `script-src 'self' 'unsafe-inline'`, as WebAgent does: simpler, but much weaker XSS protection.
Recommendation: option 1. In dev only, `'unsafe-eval'` is allowed for React refresh.
Decision: the recommendation above, accepted by the user on 2026-11-10 (plan sign-off).
Consequences: pages render dynamically (no static export). An e2e check confirms the CSP header and that there are no console CSP violations.
